# MWDAgent

地下空间工程钻注一体化智能体研究项目。

当前公开维护的研究模块：

```text
MWD/
  随钻感知地层识别与注浆决策基础
```

## 模块

- [`MWD/`](MWD/)：MWD 随钻感知数据、地层识别复现、文献任务卡和注浆决策研究方案。

后续模块可按同一层级加入，例如 `Grouting/`、`KnowledgeGraph/`、`Agents/` 和 `Experiments/`。

## 仓库约定

- 根目录只放总项目说明和全局配置；
- 每个研究模块拥有独立的 README、数据说明和文档目录；
- 论文 PDF、Office 文件、临时分析结果和本地生成文件不进入公开仓库；
- 第三方数据按原始来源许可证和使用限制执行。
