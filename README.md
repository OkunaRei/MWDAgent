# MWDAgent

地下空间工程钻注一体化智能体研究项目。

## 总体路线

按“公开数据验证方法 → 自有数据验证地质认知 → 不确定性驱动的注浆建议 → 历史回放与现场验证”推进。公开数据实验与现场数据准备同步开展。

- [总体研究与实施路线](docs/project-roadmap.md)：当前基础、六阶段里程碑、验收条件、Agent 对照实验、责任分工和范围控制。
- [现场数据与标签契约](docs/field-data-contract.md)：提前确定钻孔—深度段—注浆段关联、标签证据、时间可用性及试采集验收。

近期优先完成可信评估与现场数据契约，再验证校准、拒识和条件编排的增量价值。后续自有数据重新训练与校准；四个功能模块的职责保持清晰，独立 LLM Agent 的数量由实验决定。

当前公开维护的研究模块：

```text
MWD/
  随钻感知地层识别与注浆决策基础
```

## 模块

- [`MWD/`](MWD/)：MWD 随钻感知数据、地层识别复现、文献任务卡和注浆决策研究方案。

后续模块可按同一层级加入，例如 `Grouting/`、`KnowledgeGraph/`、`Agents/` 和 `Experiments/`。

## 仓库约定

- 根目录维护总项目说明和全局配置，`docs/` 维护跨模块路线与数据契约；
- 每个研究模块拥有独立的 README、数据说明和文档目录；
- 论文 PDF、Office 文件、临时分析结果和本地生成文件不进入公开仓库；
- 第三方数据按原始来源许可证和使用限制执行。
