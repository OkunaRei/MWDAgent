# MWDAgent 总体研究与实施路线

版本：2026-09-06。状态：执行规划；除“当前基础”外，本文描述的是待开展工作，不代表已有实验结果。

## 1. 目标与主线

保留“随钻感知—地质认知—注浆建议—工程师审批—施工反馈”的总目标。当前以公开数据验证方法，后续接入团队自有数据开展工程验证；公开数据不足不意味着取消注浆方向，也不意味着必须等待现场数据才能推进。

贯穿项目的研究问题是：**地质判断何时可信，以及系统如何依据认知可靠性选择预测、补充检查、方案建议或人工复核。**

专业模型负责数值预测，确定性程序负责数据处理和规则校验，Agent 负责需要条件判断的工具编排、证据组织和冲突处理。四个功能模块不预设为四个独立 LLM 实例；先建立可运行工作流，再以对照实验决定 Agent 数量与职责。

本文是阶段、优先级与验收条件的统一入口。[MWD 对齐说明](../MWD/docs/research-plan/project-plan-alignment.md)解释模块职责；既有论文思路作为候选研究分支。发生近期范围冲突时，以本文为准，不将旧文档中的设想视为已实现能力。

## 2. 当前基础与证据边界

| 工作 | 当前状态 | 可以支持的结论 |
|---|---|---|
| Hansen 岩性基线 | 主分支已有 48 特征、十类岩性训练及切片评价 | 已有可复现的表格分类起点 |
| 验证基准、有限优化器 | 截至本规划编写时位于 [PR #3](https://github.com/Eassion/MWDAgent/pull/3)，尚未合入主分支 | 候选配置与验证日志的工程基础；不是 Agent 有效性证据 |
| 自有数据 | 团队计划后续提供，当前公开仓库未包含 | 现在应确定采集与标注契约，不能预报数据规模或交付日期 |
| 校准、双门控、现场闭环 | 待实现与验证 | 研究假设，不预先声称性能提升 |

主分支[基线报告](../MWD/docs/research-plan/hansen2024-baseline-reproduction.md)记录公开固定划分的 Accuracy 约 0.8489、Macro-F1 约 0.8377。这是历史基线结果，不是本规划新增实验，也不是现场泛化指标。

公开 CSV 的样本是爆破循环或岩性区段的汇总统计；名称为 `raw.csv` 的文件也不是单孔原始连续时序。当前模型输入包括岩性与过渡区标记之外的 48 个 MWD 特征，不含富水破碎带、压水试验或注浆响应标签。不能把同一数据来源的其他岩体质量研究字段，默认当成当前分类 CSV 已有的字段。

原论文已研究过渡区性能下降，其过渡区标记参考后续样本岩性。因此该标记可用于离线切片评价，不作为实时已知输入；增加该切片本身不构成新的方法贡献。依据见 Hansen 等人（2024）第 1.3、3.1、3.3.2 节，DOI：[10.1016/j.tust.2024.105843](https://doi.org/10.1016/j.tust.2024.105843)。

## 3. 两条同步工作线

```text
A：公开数据 → 固定复现 → 空间评估 → 校准与拒识 → Agent 条件编排实验
                                                    │
B：现场数据契约 → 小批采集与标签复核 → 自有数据版本 ──┤
                                                    ↓
                  自有数据地质认知 → 不确定性驱动的决策
                                                    ↓
                          历史回放 → 影子运行 → 效果验证
```

公开数据阶段复用的是数据接口、评估器、校准与拒识方法、日志和工具调用协议。十类岩性标签、模型权重、归一化参数和门控阈值均需在自有数据上重新审计、训练或校准，不默认直接迁移。

## 4. 阶段、交付物与进入条件

时间为工作量估计，不是交付承诺。T0 为团队采纳规划后的启动周；D0 为首批通过数据验收的自有数据可用之日。A、B 线可由不同角色同步推进，人员不足时优先保证数据准备不被模型实验挤占。

| 阶段 | 建议窗口与依赖 | 核心工作 | 交付物与验收条件 |
|---|---|---|---|
| P0 协议与数据准备 | T0 起 1–2 周 | 固定研究问题、评估协议；确认现场字段与标签来源 | 数据清单、拆分清单、指标定义、风险登记表；每个现场必需字段有来源或明确缺口 |
| P1 公开数据可信基准 | P0 后 2–3 周 | 保留原论文复现；增加空间区块隔离与错误分析 | 可重跑脚本、数据哈希、区块与缓冲配置、逐类/逐区块结果；排查重叠及未知类别，不以最高随机划分分数替代验收 |
| P2 可靠性与条件编排 | P1 后 3–4 周 | 概率校准、拒识、质量门控；有条件再接 Agent | 相同覆盖率下的风险比较、消融与预算日志；无收益也报告，决定保留或简化方法 |
| P3 自有数据地质认知 | D0 起约 4–6 周，依赖 B 线验收 | 深度对齐、工况处理；一个主要地质目标与可靠性输出 | 独立标签审计、跨钻孔或按施工顺序的留出结果、误差与复核成本报告；仅有汇总数据时缩小到可验证任务 |
| P4 决策与历史回放 | P3 后约 4–6 周，依赖配对注浆数据及专家规则 | 从“是否补充检查/进入复核”起步，再扩展参数建议与反馈 | 版本化案例库、可执行规则、按时间回放器；建议有依据、可回退，回放无未来信息输入 |
| P5 影子运行与效果验证 | 现场条件满足后单独排期 | 记录建议、实际动作、响应与效果；组织前瞻性比较 | 及时性、复核负担和约束检查报告；有合适对照和效果数据后，才评价资源消耗与治理效果 |

每阶段结束进行一次继续/简化/补数据评审。研究结果为负不等于工程失败，但不据此宣称方法优于基线。具体性能阈值和人工复核预算由工程需求确定，在查看对应最终留出结果前登记；未登记时只报告探索性结果。

## 5. P1：先把评估基础做实

### 5.1 区分复现与泛化

保留公开固定 train/test，用于与论文流程比较；当前结果应表述为固定划分下的识别能力。新增空间评估作为方法可靠性诊断，不立即要求所有实验都做留一隧道。

空间评估按 `Tunnel` 与里程构造连续区块，记录区块边界、长度、缓冲距离和剔除样本。共享同一来源区段或重叠窗口的样本必须同组；训练与验证/测试之间的邻近缓冲区不参与训练。缓冲距离根据采样尺度、训练数据的相关性分析及工程目的确定，敏感性分析只在开发数据开展。

预测尚未开挖区段时，额外采用按施工方向向前验证，只使用决策时刻已知的历史。若缺少施工方向或时间，空间区块评估只能说明空间留出表现，不能声称实时超前预测。

先检查岩性在隧道与区块中的分布。仅在一个域出现的类别，留出该域后属于未知类别问题；应分别报告已知类别分类和未知类别拒识。不得为了分数方便静默删去未知类别，也不能直接把不支持未知标签的编码器用于该实验。

### 5.2 分离选择、校准与最终评价

所有拟合步骤，包括缺失填补、缩放、特征筛选和重采样，限定在训练折内。校准使用独立校准集或训练侧的折外预测；模型与门控阈值在开发/验证数据选择，最终评价不反向调参。

公开测试集已多次用于报告和研究方向讨论，不再称为研究全过程“从未查看”的测试集。每个脚本结束时只测试一次，并不能阻止跨轮次的适应性过拟合。新增协议需保存预先冻结的配置与拆分记录；重新拆分同一公开数据也不等于获得了全新独立证据，未来自有数据需另设最终留出。

报告逐类、普通区、过渡区和空间区块表现；固定 Macro-F1 的类别集合与缺类计分规则，避免模型预测出的类别改变平均分母。多随机种子反映算法/划分稳定性，不能当作独立工程样本；不确定性估计优先按独立区块或钻孔重采样，说明组数不足的限制。

## 6. P2：让不确定性产生可测量的价值

首先建立无门控、仅质量门控、仅置信度门控、双门控四个对照。概率校准先选一种适配表格分类器的方法，使用 Brier 分数或对数损失、校准图及 ECE 联合评价；若使用预测集合，报告集合覆盖率与大小，不把集合覆盖率解释为类别概率。跨域条件下不默认校准或保形覆盖保证仍成立。

核心指标为风险—覆盖率曲线：在相同自动处理覆盖率下比较错误风险，在相同风险目标下比较可自动处理比例；同时记录转人工数量、异常样本去向和复核成本。自有数据到位后，再加入工程定义的异常漏报和错误放行成本。

公开数据只能验证已有字段层面的质量诊断和受控扰动。特征缺失、噪声等注入实验必须保存扰动类型、幅度、种子及物理一致性检查；不能由此宣称验证了真实传感器掉线、接杆或漂移处理。不得将预测困难或过渡区标签直接定义成“低质量”来制造门控收益。

若双门控相对单置信度门控没有稳定收益，就保留更简单方案，分析信息冗余或质量定义失效，不继续堆叠模块。

## 7. Agent 的独立研究分支

区分两类用途：研发 Agent 组织审计、实验和错误诊断；现场 Agent 组织证据、选择工具并形成建议。前者的调参收益不能代替后者的决策有效性证据。

优先任务是带条件的工作流：发现字段/单位不匹配、选择缺失模态模型、定位错误集中区、处理规则冲突、请求补充信息。固定的 5 个特征组 × 2 个模型可直接穷举，单纯让 LLM 选择这些组合不预设为主要贡献。

| 对照 | 公平比较条件 | 主要评价 |
|---|---|---|
| 固定工作流/规则状态机 | 相同模型、工具、数据及硬规则 | 任务完成率、错误路由、人工介入、时延 |
| 随机搜索或 Optuna | 相同搜索空间和训练预算 | 达标所需试验数、最终留出性能、总计算成本 |
| 单 Agent，无领域诊断提示 | 保留同样的执行器与硬约束 | 领域信息与错误切片的增量贡献 |
| 知识约束单 Agent | 同样的输入信息与工具权限 | 冲突解决、证据正确性、无效动作与开销 |
| 多 Agent（可选） | 只有单 Agent 存在明确瓶颈时加入 | 对同预算单 Agent 的增益与协调成本 |

数据缺失或单位冲突若属于输入条件，应同样提供给规则基线；只有明确的消融组才移除相应信息。预先固定模型版本、提示词、工具 schema、训练次数和 token/时间上限，记录失败、重试和未完成实验；训练预算与 LLM 开销分别报告。重复运行 Agent，并在未参与提示词/策略设计的任务上评价。

硬约束由执行器统一校验，LLM 提议不能修改数据划分、接触最终测试反馈或自行越过预算。Agent 可读日志只含开发信息；最终评估作为独立命令运行，结果不回流至下一轮搜索。

进入论文主线的条件是：在相同资源条件下，Agent 在有效性或效率上达到预先定义的实际增益，且没有不可接受的可靠性退化。若不满足，作为工程辅助工具保留，不将整个项目成败绑定于 Agent 胜出。

## 8. B 线与 P3：为自有数据提前准备

立即采用[现场数据与标签契约](field-data-contract.md)。先做一批覆盖正常工况、异常和缺失情形的试采集，验证能否关联“工程—钻孔—深度段—注浆段”，再扩大采集。

先选一个工程场景、一个主要地质目标。完整性/破碎程度与富水证据分别记录；三状态输出可作为工程路由，但未知、证据不足或不符合三类定义的样本必须保留，不能强行归类。岩性类别不直接映射为富水或注浆需求。

深度对齐、工况识别和物理特征优先；表格基线稳定后，只在有真实时序且确有必要时加入一种轻量时序模型。根据实际使用目标选择跨钻孔、施工区域或按时间向前验证；跨设备和跨项目需有相应数据覆盖才能立项。

现场标签不足时可进行弱监督探索，但最终评价必须有独立可信标签。窗口很多不等于独立样本很多；所需采集量应根据独立钻孔/区域数、稀有异常数、目标置信区间与学习曲线估计，不预设一个通用行数门槛。

## 9. P4–P5：由认知连接到注浆决策

先验证一个低维决策：当前信息是否足以进入常规建议，还是需要补充检查或专家复核。在相同水文、设计和设备信息下，比较确定地质标签与地质概率/可靠性输入，确认不确定性是否实际改变并改善决策。

随后建立结构化案例检索和工程规则，逐步加入压力、流量、水灰比建议区间。规则需记录单位、适用条件、来源和版本；适用性冲突或约束交集为空时停止推荐并请求复核，不能机械地取一个数值最小的边界。比较固定规则、案例检索加规则、Agent 编排三种方案，避免把规则本身的收益全部归因于 Agent。

只有获得配对工艺、过程和结果数据后，才考虑训练响应模型。历史注浆量由地质条件和实际施工策略共同决定，预测历史用量不等于找到最优方案；治理效果也不能以注浆量较少替代。

历史回放在每个时刻只开放当时已可获得的数据、案例、模型版本和规则版本。不能使用当前案例的最终注浆量、未来配比变化、后续地质标签，或以最终时长的 20%/40% 作为在线触发时刻；采用已流逝时间或当时可观测事件。

回放可以验证状态识别、异常提前量、建议一致性、约束违反和复核负担。若 Agent 动作不同于历史动作，后续真实曲线仍是历史动作的结果，不能当作 Agent 动作的反事实效果。影子运行也主要提供可用性证据；资源消耗和堵水改善需进一步的前瞻性对照，或明确假设、覆盖范围及误差的响应/因果模型支持。

工程师审批、实际动作及原因均需记录。规则通过率不等于整体工程安全；结论限定于规则覆盖的约束和已验证场景。全过程不直接连接设备控制。

## 11. 论文与成果组织

候选第一篇聚焦“空间相关条件下 MWD 地质识别的可靠性与选择性预测”，使用公开数据建立证据，条件允许时加入自有数据外部验证。只有优于相关工作且机制与消融证据成立时，才确立具体创新表述；校准、门控或换数据集本身不自动构成创新。

候选第二篇聚焦“地质认知不确定性驱动的受约束注浆决策”，依赖现场配对数据与规则，先证明决策可靠性与复核价值，再讨论施工效果。Agent 可贯穿两篇，也可在明确优于固定编排时独立成篇；不预先承诺论文数量或录用层级。

每个研究交付都应包含：数据版本与使用范围、配置与随机种子、拆分和校准记录、基线及消融、失败案例、运行成本、可复跑入口和结论边界。现场数据默认进入受控存储；公开仓库维护代码、脱敏 schema 和经授权的汇总成果。

## 12. 范围控制与回退

| 风险/触发条件 | 调整方式 |
|---|---|
| 自有数据延迟 | 继续 P1/P2 和数据契约准备；不以模拟数据冒充现场闭环证据 |
| 标签或水文证据不足 | 缩小到可靠的地质属性；未知与弱标签单列，补采复核 |
| 空间留出后性能下降 | 将下降作为实际问题研究，不回退到随机划分证明泛化 |
| 双门控或 Agent 无增益 | 保留更简单基线，报告负结果，转向更有信息价值的数据或任务 |
| 无完整注浆过程/动作记录 | 暂停反馈策略效果主张，只做可支持的状态或案例研究 |
| 无现场效果对照 | 保留回放/影子运行结论，不声称降低耗浆或改善堵水 |

数字孪生、强化学习、自动设备控制、复杂知识图谱和大规模多 Agent 协作暂不列为完成项目的前置条件；出现明确需求及数据支撑时再单独立项。
