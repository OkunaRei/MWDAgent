# 复现任务卡：Rongved et al. (2024) 预注浆决策支持

## 1. 选定论文

**Toward machine learning based decision support for pre-grouting in hard rock**
Ida Rongved, Tom F. Hansen, Georg H. Erharter
Civil Engineering Design, 6, 63-73, 2024
DOI: https://doi.org/10.1002/cend.202400012

作者代码：<https://github.com/idarongved/pregrouting_prediction>

## 2. 为什么它比 MWD 岩性论文更贴合当前项目

这篇论文直接研究硬岩隧道预注浆决策，预测目标是：

- `Total grout take`：总注浆量，单位为 kg cement；
- `Grouting time`：单个注浆扇区/站的注浆时间，单位为小时。

输入变量覆盖三类信息：

1. 地质信息：前一掌子面 Q 值、MWD 归一化/RMS 特征；
2. 隧道几何：埋深、隧道轮廓宽度等；
3. 注浆和施工信息：水灰比/水泥类型、最大压力停止准则、注浆孔数量、前一注浆扇区的注浆量/时间/停止压力、天气信息等。

这与当前“钻注一体化地质认知与注浆决策 Agent”项目的链条直接对应：

```text
钻进感知 + 地质/水文信息 + 注浆工艺
                 |
                 v
        注浆量 / 注浆时间预测
                 |
        材料、设备、工期和注浆方案决策
```

## 3. 复现可行性和限制

代码仓库可通过 Git 获取，包含：

- 天气数据获取与合并；
- 数据预处理；
- 异常值处理；
- 特征选择；
- 超参数优化；
- ExtraTrees、KNN 等模型训练与评价；
- 预测区间和绘图脚本。

但论文使用的 Bane NOR 铁路项目数据没有公开，论文说明数据需经 Bane NOR 许可后由作者提供。因此需要区分两种复现：

### A. 严格论文复现

申请原始数据，运行作者代码，复现论文报告的特征选择、模型排名和 R² 结果。

### B. 方法复现

使用你们自己的钻井-注浆数据，按作者的 schema 映射字段，复现同一条建模流程，并明确标注为 independent implementation / method reproduction，而不是原数据结果复现。

当前更现实的是先做 B，再争取 A。

## 4. 论文基线结果

论文使用挪威铁路项目数据，文中提到约 340 个注浆站，建模数据部分为 320 个站点。这里存在样本数口径差异，复现时必须核对原始数据筛选过程。

论文报告的最佳树模型为 ExtraTreesRegressor：

- `Total grout take`：R² 约 0.40；
- `Grouting time`：R² 约 0.33。

这些是论文报告值，不是当前项目已经得到的结果。

论文结果本身并不高，但这反而适合作为项目基线：它明确显示仅依赖当前常规地质、MWD 和注浆工艺字段，难以稳定解释注浆量和注浆时间，后续创新可以围绕水文条件、裂隙连通性、压力-流量曲线和空间顺序展开。

## 5. 第一阶段复现范围

暂时不复现天气 API 和完整自动流程，先完成以下内容：

1. 审计作者代码中的数据 schema、特征列表、标签定义和训练/测试切分。
2. 提取论文中的 `utility.py` 特征组和配置文件。
3. 生成一份项目自有数据字段映射表：作者字段、项目字段、单位、时间/空间对齐方式、缺失状态。
4. 用一份脱敏或模拟的小型数据跑通 preprocessing -> feature selection -> train/eval 链路。
5. 确认 ExtraTrees、DecisionTree、RandomForest/KNN 的评价指标和图表能正常生成。
6. 在拥有真实项目数据后，再进行原数据规模的结果复现。

## 6. 后续研究扩展方向

论文已经指出，需要增加：

- 注浆前探孔/控制孔的水文信息；
- 更细粒度的岩体质量和裂隙信息；
- 注浆压力-流量-累计量的连续曲线；
- 浆液配比、黏度、凝结时间等材料信息；
- 人员、组织和合同等影响因素。

因此后续可以形成自己的研究贡献：

1. **从站点级回归扩展为注浆过程时序预测**：在注浆进行到 20%、40% 或 60% 时，预测最终注浆量和是否达到停止准则。
2. **从单点特征扩展为空间序列**：利用前后注浆扇区、孔位和四象限空间关系，避免把一个注浆扇区当成无序表格行。
3. **从总量预测扩展为风险分层**：预测低/中/高注浆需求、异常吸浆、压力异常和潜在串浆。
4. **从纯数据驱动扩展为工程约束模型**：把压力-流量-累计量、最大压力停止准则和浆液可注性作为约束或质量检查。

## 7. 与其他候选论文的关系

- `Drill Monitoring for Rock Mass Grouting: Case Study at the Stockholm Bypass`（2021，DOI: [10.1007/s00603-020-02279-w](https://doi.org/10.1007/s00603-020-02279-w)）更适合复现 MWD Fracturing Index 和“是否需要注浆/注浆消耗等级”的规则型基线。
- `Toward machine learning based decision support for pre-grouting in hard rock`（2024）更适合复现“注浆量/注浆时间”的机器学习回归基线。
- 当前项目建议先复现 2024 年回归论文，再把 2021 年 FI 规则作为可解释工程基线加入比较。
