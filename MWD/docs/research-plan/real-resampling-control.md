# 相同类别数量下的真实样本重复采样对照

## 冻结协议

研究问题：原基线的类别代价是否与 SMOTE 插值有关？以真实样本重复采样代替 SMOTE，保持原有欠采样目标及最终每类数量一致。只运行 LightGBM、完整 48 特征、五种子 11/19/42/73/101、公开训练集内部 80/20 划分，两配置共十次训练。

```bash
.venv/bin/python run_resampling_control.py --output-dir reports/resampling_control/new-run
```

paper_smote 与 real_resample 均将超过第二大类数量的类别欠采样至该数量，再将其余类别补到同一数量。前者使用插值，后者仅复制原始特征—标签对。程序核对最终类别计数、配对验证索引及切片支持数，不改变 -0.05 类别召回屏障或整体晋级要求。

该对照隔离了过采样算法及其相应重复/插值分布的影响，不能将差异解释成纯粹的“数据真实性”效应，也不能推断现场测量因果。数据仍是重复使用的随机留出验证集，不读取测试集。

## 已运行结果

产物位于 `reports/resampling_control/real-rows/`：协议、两配置逐种子 JSON、类别/混淆/配对 CSV 和 result.json。具体执行顺序为先完成基线五种子，再执行真实样本重复采样五种子；不是新 LLM 搜索试验。

| 指标均值 | paper_smote | real_resample |
|---|---:|---:|
| Balanced Accuracy | 0.8446 | 0.8370 |
| 整体 Macro-F1 | 0.8224 | 0.8256 |
| 过渡区 Macro-F1 | 0.5632 | 0.5599 |
| 综合分数 | 0.7491 | 0.7482 |

整体晋级要求未满足。同时，7 个类别—种子组合违反每种子召回下限：Augen_gneiss 在种子 11、42、73、101 均下降约 0.10；Hagaberg_shale 在种子 19、73、101 分别下降约 0.1111、0.1852、0.0741。最差差值为 -0.1852。

结果不支持把真实样本重复采样作为替代基线，也不能断言此前少数岩性退化主要由 SMOTE 引起。实现作为 benchmark 的 `real_resample` 动作原语保留，但未扩充既有 Agent 版本目录或修改历史晋级规则。至此，类别权重、中点 SMOTE 和真实样本重复采样均未同时通过当前整体及逐类别约束。

## 核心研究决策

保留原始 paper_smote 基线。结束这一组采样假设的逐项扩展，不通过继续微调比例追逐既有验证集。下一轮应在冻结的任务包中，让 Agent 读取这些负结果和类别证据，并比较“停止”与有限替代动作的选择；若评估搜索效率，必须披露这些结果已被本宿主看到，使用独立宿主上下文和固定预算。独立上下文也不能消除历史数据选择偏差，结果仍需限定为开发集策略评估。

上一轮中点策略的 v3 会话 `reports/agent_loop/midpoint-v3/` 确认因最差类别召回 -0.15 被拒绝。本轮补齐中点数量、单样本类别、非法比例、确定性和 v3 动作传播/屏障测试。真实样本重复采样支持单样本类别，SMOTE 分支明确拒绝无法插值的单样本类别。
