# 类别权重候选的逐岩性代价

## 问题与协议

LightGBM + balanced 类别权重在既有五种子验证中通过综合评分、整体 Macro-F1 和过渡区 Macro-F1 的晋级规则，但 Balanced Accuracy 下降。本轮仅解释这一权衡，不重新选择配置或修改晋级下限。

```bash
.venv/bin/python analyze_strategy_impact.py --output-dir reports/strategy_impact/new-run
```

固定 LightGBM 参数、完整 48 特征、五种子 11/19/42/73/101、80/20 公开训练集内部划分。对 paper_smote 和 class_weight 各运行五次，保存整体、普通区、过渡区的混淆矩阵、类别报告和验证行号。每对种子的类别顺序、验证行号、真实类别支持数必须完全一致才能比较。

输出包含每种子/切片/岩性的精确率、召回率、F1 和支持数，以及非对角混淆计数。召回率在支持数为零时为 null，不作为零值平均；同一样本可在不同种子的验证集中重复出现，因此合并混淆计数只能称为预测出现次数，不能称为独立样本数。

Balanced Accuracy 在这里是有样本类别的召回率平均；Macro-F1 同时受精确率和召回率影响。两者方向不同并不矛盾：减少误报可能提高精确率与 F1，同时增加某些类别的漏判。混淆去向是模型行为证据，不证明岩性或测量的物理因果关系。

## 2026-09-09 结果

十次训练完成，逐种子指标复现前一轮研究。证据位于 `reports/strategy_impact/2026-09-09/` 的两份策略 JSON、class_rows.csv、confusion_rows.csv、paired_rows.csv 和 impact.json。

| 岩性 | 基线召回率 | 类别权重召回率 | 差值 | 基线 F1 | 类别权重 F1 |
|---|---:|---:|---:|---:|---:|
| Augen_gneiss | 0.8500 | 0.6400 | -0.2100 | 0.6747 | 0.6638 |
| Amphibolittic_gneiss | 0.7885 | 0.6345 | -0.1540 | 0.6924 | 0.6851 |
| Hagaberg_shale | 0.6741 | 0.6000 | -0.0741 | 0.7235 | 0.6867 |
| Granittic_gneiss | 0.7491 | 0.8914 | +0.1422 | 0.8116 | 0.8608 |
| Blackshale | 0.8032 | 0.8323 | +0.0290 | 0.8061 | 0.8187 |

表中为五种子均值。Augen_gneiss 与 Amphibolittic_gneiss 的召回率在全部五个种子中下降，前者各次下降 0.10 至 0.30，后者下降约 0.103 至 0.218。它们的精确率反而从 0.5614/0.6197 提升到 0.6959/0.7487，因而 F1 降幅小于召回率降幅。这说明只看 Macro-F1 会掩盖部分漏判代价。

合计五种子验证出现次数，Amphibolittic_gneiss → Granittic_gneiss 由 90 增至 159 次，Augen_gneiss → Granittic_gneiss 由 12 增至 35 次。不是独立样本计数；它们显示类别竞争发生变化，不证明训练样本处理是唯一成因。

过渡区也存在同向退化：Augen_gneiss 召回率均值约 0.8250 → 0.4976，Amphibolittic_gneiss 约 0.6701 → 0.4853；Granittic_gneiss 则约 0.5024 → 0.7450。若某种子切片没有该类，均值排除无定义召回率。过渡区总体 F1 改善并不等价于每个边界类别都改善。

## 决策与下一步核心工作

保留原 Agent 会话“通过当时规则并晋级”的历史事实；将该策略定位为存在类别退化的研究候选，不改成默认基线。原规则只保护整体和过渡区 Macro-F1，没有逐岩性召回约束，因而不能作为类别安全屏障。

下一版 Agent 的观察需要暴露逐类别召回变化和支持数，使宿主能识别多数类收益掩盖的退化；若新增类别保护规则，必须另行冻结规则版本与容忍度，不能倒改旧实验或对同一数据进行阈值搜索后宣称独立有效。当前没有注浆风险标签，也不能给这些岩性臆造工程危险等级。

## 2026-09-09 类别安全屏障接入

training-strategies-v1 已把 `minimum_class_recall_delta = -0.05` 写入版本化策略：相对 paper_smote 基线，任何类别召回下降超过 0.05，候选不能晋级。该阈值是在看到本轮诊断后为下一协议冻结的安全约束，不回溯修改上一轮“class_weight 通过整体规则”的历史结论。

新会话 `reports/agent_loop/2026-09-09-class-floor/` 复跑基线和 class_weight。类别权重仍有综合分数差值 `+0.006284`、整体 Macro-F1 差值 `+0.004543`、过渡区 Macro-F1 差值 `+0.030409`，但最差类别召回差值 `-0.300000`，执行器以 `class_recall_floor` 拒绝晋级。会话没有读取测试文件。

这项屏障保护了逐类别漏判，却不是工程安全阈值：类别标签不等于富水、破碎或可注浆性状态。阈值的合理性还需要独立任务和现场证据验证，不能把它直接写成注浆风险规则。

进一步数值动作应针对这个明确权衡研究，例如减少欠采样强度或使用真实样本重复采样，以便区分多数类信息保留和 SMOTE 合成点的影响。本轮不立即扩展搜索，避免依据单次目录反复调参；先将类别退化反馈纳入下一版核心决策接口与冻结比较协议。


## 类别反馈 v2 修订

上一轮将类别屏障直接加到 training-strategies-v1 的做法不符合版本隔离要求。现已恢复原始 v1（仅整体/过渡区晋级条件），另设 training-strategies-v2。上一轮 class-floor 会话保持原始文件，仅作为误标版本的历史实验，不应恢复执行或视为原始 v1。

新会话入口：`run_mwd_agent.py init --strategy-actions --class-guard --budget 2 --session <新目录>`。v2 按每个种子的整体切片类别召回检查 -0.05 下限，边界使用 1e-12 浮点容差；普通区/过渡区类别数据也供观察，但不单独触发此屏障。无支持数的类别不伪造零召回。

反馈包含每个类别/种子的支持数、基线与候选召回率、差值、精确率/F1 及违反列表。指标从配对混淆矩阵重算，校验种子、类别和验证行一致性；缺失或损坏的证据导致记录失败、消耗候选预算且保留 incumbent。初始基线缺失诊断则停止。

对 `reports/strategy_impact/2026-09-09/` 已冻结的两组五种子结果进行缓存证据回放，输出 `reports/class_guard_v2/2026-09-09/replay.json`：15 个类别—种子违反项，涉及 Amphibolittic_gneiss、Augen_gneiss、Blackshale、Hagaberg_shale，候选被拒绝。回放未新增模型训练，也不是一次新的盲测 Agent 搜索。状态中的耗时为读取缓存评估器耗时，不是原训练成本。
