# 扩展采样与类别权重动作

## 研究问题与冻结配置

上一轮特征删减没有产生同时满足整体与过渡区下限的候选。本轮检验训练分布处理是否造成信息损失：欠采样会移除部分多数类观测，SMOTE 会引入合成特征点；保留全部原始样本及类别权重是有明确差异的替代动作。

固定完整 48 特征、既有模型参数、五种子 11/19/42/73/101、公开训练文件内部 80/20 分层划分和 0.2/0.5/0.3 评分权重。六候选为 LightGBM 与 ExtraTrees 分别搭配：

- paper_smote：原有欠采样后 SMOTE，无类别权重。
- original：保留原始训练子集，无重采样、无类别权重。
- class_weight：保留原始训练子集，使用模型的 balanced 类别权重；权重仅根据拟合子集计算。

```bash
.venv/bin/python run_sampling_study.py --output-dir reports/training_strategies/new-run
```

协议、源数据哈希、代码哈希和依赖版本先于模型拟合写入；每个候选完成后单独保存逐种子结果及采样前后的真实岩性样本数。固定六候选最多 30 次训练，不在看到结果后调整本轮目录。输出目录必须不存在。

## 评价与解释

相对原有 LightGBM + paper_smote 基线，综合评分提升须严格大于 0.001，同时整体和过渡区 Macro-F1 均值均不低于基线。只有满足这三个条件才标记为 promotable_vs_baseline；该标记是预设规则判断，不代表统计显著性。

本轮是数值模型动作空间研究，不是 LLM 决策效率实验。各候选共用随机验证行，而且这些公开训练样本已被既有实验探索，不能作新的独立泛化证据。类别权重可能改善少数类召回而损害概率校准，因此即使通过晋级规则也需后续概率质量检查。训练中不读取公开测试文件。

新训练策略通过 `run_validation_once(..., training_strategy=...)` 提供。默认仍为 paper_smote，因此旧入口的数值流程不变。旧 Agent 会话记录了执行代码哈希，更新后应保留其历史报告用于观察/回放，不应绕过哈希校验继续旧会话。

## 与核心 Agent 的衔接

原四候选 Agent 默认目录保持不变。新增 training-strategies-v1 策略显式包含三个训练策略、六个候选；通过 `run_mwd_agent.py init --strategy-actions --budget 3 --session <新目录>` 创建，不修改历史会话。后续 act/observe 从状态读取策略版本，无需再次传入开关。旧四候选搜索回放工具仍仅支持旧协议，不能混用本轮六候选结果。

## 2026-09-09 实测

六候选各五种子，共 30 次训练，输出 `reports/training_strategies/2026-09-09/`。

| 模型 | 策略 | 整体 Macro-F1 | 过渡区 Macro-F1 | 综合分数 | 通过晋级条件 |
|---|---|---:|---:|---:|---|
| LightGBM | paper_smote | 0.8224 | 0.5632 | 0.7491 | 基线 |
| LightGBM | original | 0.8218 | 0.5772 | 0.7452 | 否 |
| LightGBM | class_weight | 0.8270 | 0.5936 | 0.7554 | 是 |
| ExtraTrees | paper_smote | 0.8155 | 0.5697 | 0.7477 | 否 |
| ExtraTrees | original | 0.8035 | 0.5398 | 0.7209 | 否 |
| ExtraTrees | class_weight | 0.8006 | 0.5427 | 0.7196 | 否 |

LightGBM + class_weight 的综合分数提高 0.006284，过渡区 Macro-F1 提高 0.030409；整体 ECE 均值由 0.087889 降至 0.072623。但 Balanced Accuracy 从 0.844615 降到 0.819061，晋级规则未对该指标单设下限，不能宣称所有指标均改善。

配对种子差异如下；五次验证共享样本，不能当作五次独立外部试验。

| 种子 | 综合分数变化 | 整体 Macro-F1 变化 | 过渡区 Macro-F1 变化 |
|---|---:|---:|---:|
| 11 | -0.011551 | -0.002157 | -0.015291 |
| 19 | +0.014704 | +0.022344 | +0.019747 |
| 42 | +0.003356 | +0.013400 | +0.000553 |
| 73 | +0.025763 | -0.016120 | +0.144030 |
| 101 | -0.000853 | +0.005250 | +0.003009 |

改善并非每种子一致，过渡区平均提升很大程度受 seed=73 影响。结果支持保留候选，不证明稳健优势。

随后会话 `reports/agent_loop/2026-09-09-strategies/` 在六候选、预算三个候选的协议下，实际执行基线和 class_weight 共 10 次训练，复现结果并晋级；宿主提交 stop 动作，终态 stopped，剩余一个预算。本轮合计 40 次训练。提案明确披露宿主已知上述六候选结果，因此这条轨迹是工程集成验证，不能作为独立 Agent 搜索效率结果。

下一步核心问题是：新增策略改变了哪些类别的召回/误判，以及在独立冻结的策略比较协议下，Agent 能否比随机搜索更有效选择动作。不得把本轮已知优胜候选放入目录后，用同一宿主的记忆伪装盲测。

逐岩性诊断现已完成，见 [strategy-class-impact.md](strategy-class-impact.md)。Augen_gneiss 与 Amphibolittic_gneiss 在五个种子中均出现召回下降；因此保留历史晋级事实，但不将该研究候选替换为默认基线。下一版决策需要显式暴露这种类别权衡。

## 下一动作：中点欠采样（待执行）

新增 `undersample_majority_then_smote` 作为固定动作原语，保留最大类与第二大类数量差的一半，再对其余类别执行 SMOTE。该动作尚未纳入已完成结果；执行前需固定候选目录、预算和类别召回屏障。

## 2026-09-10 中点欠采样结果

新增 midpoint_smote 后完成八候选、40 次训练。LightGBM + midpoint_smote 的整体 Macro-F1 为 0.8307、过渡区 Macro-F1 为 0.6053、Balanced Accuracy 为 0.8387、Selection Score 为 0.7647；相对 paper_smote 基线分别为 +0.0083、+0.0421、-0.0059 和 +0.0156。它超过当前整体/过渡区晋级门槛，但尚未经过 v2 逐类别召回屏障复核。

ExtraTrees + midpoint_smote 的 Selection Score 为 0.7467，未通过晋级。中点策略减少最大类欠采样幅度，可能同时保留多数类信息并减少合成点偏移；这一解释仍是待验证假设。下一步只把 LightGBM + midpoint_smote 放入独立 v3 Agent 会话，要求逐类别召回下降不超过 0.05，并补做概率校准与类别影响分析。

后续状态：v3 会话已完成，中点候选因逐类别最差召回差值 -0.15 被拒绝，默认基线未改变。相同类别数量下的真实样本重复采样对照也已完成，详见 [real-resampling-control.md](real-resampling-control.md)。当前暂停继续调节采样比例，避免重复开发集上的无界搜索。
