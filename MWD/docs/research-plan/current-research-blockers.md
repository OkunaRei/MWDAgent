# 当前研究问题与阶段性交付

## 本阶段范围

本阶段只推进 MWD 岩性模型研发 Agent：扩展有限采样动作、向决策提供类别错误证据、拦截不合格候选、开展同预算和反馈消融。注浆决策与现场效果验证不在本阶段范围内。已合并的旧 PR 提供基准平台；此次增量不增加人工质量标注工具或工程决策模块。

## 已完成的核心实验

- LightGBM 类别权重、中点 SMOTE 提高整体/过渡区均值，但存在部分岩性召回下降。
- 在类别数量相同的条件下，以真实样本复制替代 SMOTE，仍未通过整体及类别要求。
- v2/v3 明确版本化逐种子、逐类别召回屏障，观察提供支持数与退化证据。
- 独立上下文宿主在八候选、三个候选预算下完成两步决策，与固定顺序及42种随机顺序持平。
- 首对反馈消融轨迹只改变可见诊断，动作顺序不同但最终结果相同；首步差异早于反馈，不能归因于类别证据。

## 尚未解决的三个问题

**候选目录缺少合格改善机会。** 当前候选在全部规则下无法替换基线。因此同预算搜索最终全部持平，不能证明 Agent 更有效，也不能据此证明所有 Agent 方法无效。继续重排相同候选或增加回放次数不会创造区分力。

**类别屏障缺少独立依据。** 逐类别召回下降不超过0.05，是观察到类别退化后加入的研究约束。某些类别每个验证种子约20条样本，一条错分就对应0.05，逐种子最差值对样本波动敏感。这个屏障已正确执行，但尚未证明它是合理的工程风险或统计可靠性要求。后续应先论证容忍度、样本支持与评价目的，不能为使某个已知候选通过而放宽阈值。

**开发数据重复使用。** 相同训练文件和随机留出种子已经历多轮候选开发与规则设计。新模型上下文隔离了对话记忆，未消除候选设计和数据选择偏差。当前结果不能替代独立测试、空间泛化或现场验证。

## 为什么暂停继续增加候选和接口

近期推进出现了“补接口、跑小实验、再补接口”的循环。执行能力和审计记录有所改善，但没有同步形成更强的研究证据。刚提出的四上下文、相同中间状态的配对消融尚未执行；不把它列为完成，也不在本 PR 中增加占位实现。

下一步优先作研究决策，而不是再扩充搜索次数：

1. 明确首要主张是提升预测性能，还是提升实验决策效率。
2. 根据主张预先定义主指标、预算、约束依据以及独立评价任务；若缺少可用改善候选，应设计具有区分力的任务，不能依靠有利目录挑选。
3. 在方案冻结后执行多次独立宿主轨迹和相同中间状态的配对消融，完整披露开发集历史。

此次提交适合作为研究进展草稿：审查代码的训练隔离、策略兼容、类别反馈与结果遮蔽，以及上述问题是否表达清楚。它不主张 Agent 优于随机搜索，不替换 paper_smote 默认基线，不改变历史会话结果。新生成的实验 JSON/CSV、模型宿主记录和本地资料继续保留本地；研究文档包含复现入口及实测数值。
