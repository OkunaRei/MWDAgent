# 独立宿主上下文的有限预算决策对照

## 执行前固定的设计

沿用 training-strategies-v3 八候选目录，包含两模型与原始分布、类别权重、paper_smote、中点 SMOTE。每条策略预算三个候选，含基线，最多选择两个后续动作。选择分数、整体/过渡区下限和每种子逐类别召回 -0.05 下限保持不变。

这轮使用一个不继承已有会话的新宿主上下文。宿主只收到 [decision-host-prompt.md](decision-host-prompt.md) 和已选候选的精简观察，不能使用文件、工具或旧报告。逐轮原始动作与反馈保留供审计。它是一次真实模型决策轨迹，不是代码生成的顺序；候选执行仍由确定性的受约束工具负责。

完整候选表按固定五种子统一生成，每候选五次训练，总计40次。随后决策执行查表，记录虚拟训练预算与已揭示候选；不会为每个随机顺序重复训练。执行器会读取并校验全部缓存记录，但未执行候选结果不进入宿主观察；完整对照仅在宿主停止后生成。

## 对照

固定策略按冻结目录前三项执行。随机策略枚举基线后七个候选中有序选两个的全部42种轨迹，均采用同样晋级规则，不提前知道候选结果。宿主可以在用完预算之前停止，比较结果必须同时列出得分与实际消耗候选数，不能将剩余预算当作测量到的时间节省。

比较表包括最终可用分数、是否达到改善目标和未使用预算；整体与过渡区指标保留在候选文件与宿主状态文件。随机42条是同一结果表上的精确排列，不是独立数据或42次语言模型运行。未约束 Agent、无切片反馈、多次独立宿主轨迹仍属于后续实验，不包含在本轮范围内。

## 可复现入口

```bash
.venv/bin/python run_decision_benchmark.py prepare --dir reports/decision_benchmark/new-run
.venv/bin/python run_decision_benchmark.py observe --dir reports/decision_benchmark/new-run
```

prepare 在训练前写入协议与来源/代码/依赖指纹；输出仅报告进度。宿主从 observe 获取观察，提交结构化动作给 act，直到 stopped，然后 compare 输出对照报告。这里的隐藏是宿主输入协议和独立上下文隔离，不是操作系统文件权限沙箱。

## 研究边界

新上下文避免继承当前对话中的具体成绩，但不能消除目录和屏障已经受历史开发结果影响这一事实。数据与随机划分也早已被多轮使用。因此本轮是开发集上的受限决策评估，不是独立泛化试验，也不保证候选目录有改善机会。禁止在结果出来后为了显示 Agent 优势而放宽约束、改目录或换统计口径。

缓存表的40次训练成本与宿主策略的虚拟候选预算分开报告。宿主 token/推理耗时若没有可靠计量则留作未计量，不用总工具时间替代。只进行一次宿主轨迹，不能估计模型间或运行间方差。

## 首轮实际轨迹与结果

产物位于 `reports/decision_benchmark/fresh-host-01/`：protocol.json、八份候选文件及校验清单、三份状态与观察、comparison.json/csv，以及 host-transcript.json。

决策宿主通过 `fork_turns=none` 创建，没有继承当前线程。它在编排记录中未调用工具，第一轮仅收到基线和目录，第二轮仅增加其选择的原始分布候选反馈。两次返回动作未经修改交给执行器；各动作哈希已核对绑定其前一观察。转录另标记终态观察未再次发给宿主，避免把生成记录当成已交付消息。

1. 基线观察：分数 0.749084、整体 Macro-F1 0.822407、过渡区 0.563191。
2. 宿主选择 LightGBM + original，理由是固定模型，检验保留原始样本/分布。执行器返回分数 0.745157、整体 F1 0.821755、过渡区 F1 0.577201；四种岩性存在类别召回违规，未晋级。
3. 宿主据此选择 LightGBM + class_weight，假设 balanced 权重可修复原分布下观察到的类别退化。执行器返回分数 0.755368，但类别屏障仍未满足，拒绝晋级并按预算停止。

| 方法 | 候选评估预算/使用 | 最终分数 | 改善目标达成 |
|---|---:|---:|---:|
| 新上下文宿主，1条轨迹 | 3/3 | 0.749084 | 否 |
| 固定目录顺序 | 3/3 | 0.749084 | 否 |
| 随机有序两步，42条 | 每条3/3 | 均值/最小/最大均0.749084 | 0/42 |

宿主实际选择恰好与固定前三项一致，最终均保留 paper_smote。这里不能把“两条顺序一致”说成两次独立 Agent 复现。最终基线整体 Macro-F1 0.822407，过渡区 Macro-F1 0.563191。八候选中没有在当前屏障下带来可用提升的路径，不能由本次平局推断 Agent 对其他动作空间无效。

本轮实际新增40次准备训练；宿主只揭示三个候选，相当于15次拟合预算，执行动作时不再训练。记录了两个真实模型提案，0次提案被动作格式校验拒绝；模型候选未晋级不是非法提案。宿主 token 和推理耗时未计量，不能作成本优势结论。

这次推进的是独立上下文、已选结果反馈、真实逐轮提案和同预算比较的完整链路。当前仍缺少可验证的性能优势，不应继续通过同一开发集上的阈值调整制造优势。下一项研究应评估独立任务/数据与任务约束的合理性；若做反馈消融，应固定同一信息预算并使用多条新上下文轨迹，且先明确当前目录缺乏晋级机会的限制。
