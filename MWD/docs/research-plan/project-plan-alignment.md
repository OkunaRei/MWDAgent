# MWD 模块与总方案对齐说明

本文件将 `MWD` 模块与总项目《地下空间工程钻注一体化地质认知与注浆决策智能体研究方案》对齐。总方案是项目的上位设计，公开 MWD 论文和数据只承担“随钻地质认知”阶段的可复现实验。

执行阶段、近期优先级与验收条件统一见[总体路线](../../../docs/project-roadmap.md)，采集准备见[现场数据契约](../../../docs/field-data-contract.md)。本文的后续能力属于规划，不表示已实现。

## 1. 总体目标

项目的最小闭环为：

```text
随钻感知 -> 地质认知 -> 注浆方案生成 -> 工程师审批 -> 注浆反馈 -> 建议修正
```

系统保留四个核心功能模块，可由确定性工作流与 Agent 共同实现；是否拆为四个独立 LLM Agent 由对照实验决定：

| Agent | 职责 | 禁止越界 |
|---|---|---|
| 随钻感知 Agent | 时间同步、深度对齐、工况识别、质量控制、区段划分、特征构建 | 不直接判断岩性或注浆参数 |
| 地质认知 Agent | 预测可靠地质属性、识别富水破碎等异常、输出概率和不确定性 | 不直接输出可注性、扩散半径或最优注浆参数 |
| 注浆决策 Agent | 检索案例、结合工程条件生成压力/流量/水灰比建议 | 不绕过规范、设计文件、设备能力和专家审批 |
| 注浆反馈 Agent | 从压力—流量—累计注入量曲线识别施工状态并提出有限动作建议 | 不直接控制注浆泵 |

## 2. 当前公开数据的正确定位

当前数据集为 Hansen 等人的 15 条挪威硬岩隧道 MWD 数据：

- 数据：<https://doi.org/10.5281/zenodo.10358374>
- 论文：<https://doi.org/10.1016/j.tust.2024.105843>
- 数据目录：`MWD/data/mwd_rocktype_10358374/`

当前分类 CSV 包含 MWD 汇总特征、岩性、位置与过渡区等字段，不包含单孔原始时序，也不能默认包含相关论文使用的 Q 值等其他字段，可用于：

1. 验证 MWD 特征读取和数据契约；
2. 复现 `MWD -> Rock` 岩性预测；
3. 进行过渡区离线切片分析；聚类作为另行定义标签与评价的扩展；
4. 验证空间区块切分、特征层面的质量门控和概率校准接口。

该数据不包含富水破碎带真实标签、地下水压力、Lugeon、注浆量、注浆时间或压力—流量—累计注入量曲线。因此不能用它声称已经完成现场富水破碎带识别或注浆量预测。

## 3. 最小研究任务

总方案将地质认知限定为三个核心状态：

1. 完整或相对完整围岩；
2. 一般破碎围岩；
3. 富水破碎带。

在现场数据不足时，先用公开 MWD 数据完成岩性/过渡区基线；获得可靠现场标签后，再训练三状态任务。富水破碎带标签必须由地质编录、取芯、孔内电视、出水/漏液记录或压水试验等证据构成，不能根据单一 MWD 参数反向制造。

完整性/破碎程度与水文证据分别记录，再形成工程状态；保留未知、证据不足和不适用类别，不将所有样本强制归入三类。

## 4. 复现和扩展路线

### 阶段一：随钻感知与地质认知

```text
原始钻进时序
  -> 时间同步与深度对齐
  -> 接杆/停钻/空转/卡钻等工况识别
  -> 稳定钻进段和变化点划分
  -> 物理/统计特征与数据质量评分
  -> 岩性、过渡区或三状态预测
```

公开数据阶段保留论文固定划分用于复现，新增空间区块隔离诊断；留一隧道前先审计类别覆盖。自有数据到位后，根据实际部署目标选择跨钻孔、施工区域或按时间向前验证，不将相邻窗口随机拆分用于证明泛化。只有获得真实时序后，再比较 TCN 或轻量时序模型；跨设备/项目验证依赖相应数据覆盖。

### 阶段二：不确定性进入注浆决策

地质认知输出不应只有一个类别，而应包括：

- 类别概率或预测集合；
- 数据质量；
- 模型不确定性；
- 证据特征；
- 人工复核建议。

采用“数据质量—预测不确定性双门控”：

- 高质量、高置信度：进入常规方案；
- 中等置信度：同时生成常规方案和保守方案；
- 低质量或高不确定性：触发补充检查或专家复核。

### 阶段三：案例与规则驱动的注浆建议

注浆决策 Agent 综合地质结果、地下水条件、孔深、设备能力、材料试验、设计文件、规范和历史案例，输出：

- 浆液类型和水灰比区间；
- 初始压力、压力上限和流量范围；
- 注浆顺序与分段方案；
- 浆液切换和停浆条件；
- 备选方案、适用条件和证据链。

数据量不足时采用“相似案例检索 + 确定性工程规则”，不把大语言模型作为数值预测器。

### 阶段四：注浆反馈和历史回放

从压力、瞬时流量和累计注入量曲线识别少量关键状态：正常建立压力、低压大流量、压力快速升高、异常流量增大、疑似串浆冒浆和达到停浆条件。

动作限定为保持、升压、降压、限流、调浓、换浆、暂停检查和结束。先采用历史过程回放，保证每个时刻只使用当时已经获得的数据；之后再进入现场影子运行，由工程师审批，不直接控制设备。

回放和影子运行先评价状态判断、建议及时性、复核负担及已编码约束。若建议动作不同于历史动作，历史后续响应不能作为建议动作的反事实结果；耗浆、工期和堵水改善需要进一步的效果验证。

## 5. 核心创新和验证

优先验证以下三项，而不是堆叠网络结构：

1. 数据质量—预测不确定性双门控；
2. 地质认知纠错—注浆反馈嵌套双闭环；
3. 确定性安全屏障与可追溯证据链。

主要对照包括：无门控/单门控/双门控、确定标签决策/概率分布决策、固定规则/案例检索/模型与规则融合、无反馈/规则反馈/模型加规则反馈。

评价指标包括地质 Macro-F1、异常召回率和漏报率、边界误差、校准误差、跨域性能下降，以及注浆建议的安全约束违反率、专家采纳率、异常提前量、停浆判断误差和建议稳定性。

## 6. 当前第一篇复现的表述

当前不宜把研究表述为“MWD 注浆量预测”。更准确的阶段性表述是：

> 面向预注浆决策的随钻感知岩体状态识别与不确定性建模。

待获得钻孔—注浆段配对数据后，再扩展到：

```text
MWD + 地质 + 水文 + 注浆工艺
  -> 注浆状态、注浆量、注浆时间和治理效果
```
